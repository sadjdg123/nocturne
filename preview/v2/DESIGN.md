## 设计主张：深夜观测台

夜曲是每天打开的私人起始页。V2 的高级感来自**排版、光和层次**，不是霓虹和粒子：
- 时钟是主角（大号 Cormorant Garamond 细体，等宽衬线数字），像观测台墙上的计时器；
- 整个页面只有一处「表演」：切换空间时穹顶光转动并换色；
- 琥珀色只给交互（当前空间指示条、选中的搜索引擎、勾选框、主按钮），冷青色只给信息（在线环、延迟数字），其余都是纸色与雾灰。

## 字体（全部沿用仓库已自托管的字体，未新增字体文件）

| 角色 | 字体 | 用法 |
| --- | --- | --- |
| 时钟、在线数、海报大字母 | Cormorant Garamond 300 / 400 italic（`public/fonts/`） | 开启 `lnum` + `tnum`：等高等宽数字，秒数跳动不晃 |
| 品牌、空间名、分组标题、问候 | Noto Serif SC 500（`public/fonts/` 子集） | 字距 .06–.12em |
| 界面正文、按钮、数据 | 系统无衬线（PingFang SC / Noto Sans CJK SC） | 数字统一 `tabular-nums` |

不用：全大写眉标、中点拼接的元信息、等宽字体标签、按钮上的「→」。

## 三层背景与材质

1. **壁纸层**：复用现有默认壁纸 `public/bg-desktop.jpg`（2400×1340，280 KB）/ `bg-mobile.jpg`（704×1520，60 KB），所有空间共用用户壁纸。
2. **光层（纯 CSS）**：每个空间一层「穹顶光」= 大径向渐变 + 锥形光束（conic-gradient）；上面压一层暗角（径向 + 自上而下线性渐变）和 5% 静态噪点（160px PNG，内联）。
3. **内容材质**：只有一种材质语言——半透明午夜蓝渐变 + 1px 纸色细边 + 顶部内高光。
   - 毛玻璃（backdrop-filter）同屏最多 **2 处**：桌面 = 搜索栏 + 打开的浮层；手机 = 搜索栏 + 底部 dock（打开浮层时第 3 处）。卡片、侧栏、观测记录都**不用模糊**，靠渐变压暗。
   - 不是每张卡都发光：只有离线点有一圈淡色晕，悬停时卡片只抬 2px + 边框变亮。

## 空间布局

桌面 1440×900：左栏 220px（品牌、空间索引带数量、管理空间、网络三态按钮、账户）｜中栏（时钟 + 问候 + 当前空间标题 → 搜索 + 引擎 → 分组）｜右栏 282px「观测记录」（在线环、响应延迟、最近使用、「模拟数据」标记）。
1024–1199：观测记录落到正文下方两列；< 900（手机/平板）：独立布局。

| 空间 | 光色 | 密度 / 卡片 | 标题层级 |
| --- | --- | --- | --- |
| 全部 | 中性午夜蓝，冷白光束 | 舒适：横向卡（徽记 + 名称 + 描述），「常用」分组为胶囊链接 | 衬线 18px + 渐隐细线；被多个空间引用的分组标注「出现在 N 个空间」 |

| 娱乐 | 深靛紫 + 紫罗兰侧光 | 海报卡：4:4.4 色调封面，大号 Cormorant 首字母裁切出血，衬线标题 | 衬线 26px，去掉细线，留白更大 |

## 动效

| 时刻 | 做法 | 时长 |
| --- | --- | --- |
| 页面载入 | 壁纸淡入 → 暗角 → 侧栏/观测记录淡入 → 时钟、搜索、分组依次上浮 10px | 500–700ms，分层延迟 60–260ms |
| **切换空间（标志性）** | 旧穹顶光顺时针转出 14° 并淡出，新穹顶光从 −14° 转入、缩放 1.06→1 并淡入（只动 opacity/transform）；左栏琥珀指示条滑到新位置；分组先 150ms 淡出下沉 6px，再按 45ms 间隔逐组上浮淡入；切换时锁住内容区高度，无布局跳动；只有已滚过分组顶部时才回滚到分组顶部 | 光 660ms；指示条 420ms；内容 150 + 340ms |
| 卡片 | 精细指针（`hover:hover and pointer:fine`）才有悬停上浮；触屏只有按下缩放 .975 | 80–280ms |
| 浮层 | 遮罩淡入 + 面板位移/缩放（命令面板从上 8px、侧板从右 24px、手机抽屉从下 32px）；Esc / 点遮罩关闭；关闭后焦点回到触发按钮；Tab 焦点循环在浮层内 | 220–260ms |
| 减少动态效果 | 全部动画和过渡取消（`transition:none`），色调瞬时切换，不位移 | 0 |

没有持续 rAF 循环：时钟用对齐整秒的 `setTimeout`，标签页隐藏时停止；其余全是事件触发的 CSS 过渡。

## 交互

- 空间：左栏点击 / 手机底部切换器 / `Alt+1…5` / 命令面板「> 切换到…」。当前空间只存本机（预览中存 `localStorage`，已 try/catch；沙盒 iframe 无存储时照常运行）。
- 网络三态：自动 / 内网 / 外网，菜单内说明每种的地址规则 + 探测结果（模拟）。切换后 NAS 行地址、命令面板「内网/外网」标记、延迟列表一起变化；**不随空间切换改变**。
- 命令面板 `⌘K` / `Ctrl+K` / `/`：**跨全部空间**搜索，分层「名称匹配 → 别名匹配（如 mp → MoviePilot）→ 其他匹配 → 网页搜索」，每行标注所在分组与将走的线路；输入 `>` 进入操作模式（切换空间、改网络、管理空间、刷新状态）；↑↓/Enter/Esc。
- 管理空间：勾选分组、重命名、上移/下移、删除（只删关系）、按「日常/娱乐/NAS/空白」模板新建（只起名，不猜项目）；名称不能为空、不能重名、最多 12 个；「全部」固定不可删。
- 长按项目进入编辑模式（与 V1.1 一致）；dock「编辑」同样进入；短按打开。
- 设置抽屉演示「本设备外观：经典 / 新版」开关的位置。

## 模拟内容（预览专用，正式版不使用）

- 在线状态与延迟全部是**模拟数据**，界面上有「模拟数据」标记和说明文字；正式版沿用 V1.1 服务端真实检测。
- 服务清单、地址（`192.168.1.x` / `*.example.com`）、最近使用时间均为示例。
- 点击项目/搜索不跳转，只提示将打开的地址。
- 图标为统一的字母徽记（仓库内没有离线 Iconify 图标集）；正式版继续用用户自定义图标。

## 阶段 1–4 实施计划

1. **空间模型 / 迁移 / 测试**：在同步配置里新增 `spaces: [{ id, name, groupIds, theme?, density? }]`，只引用分组 ID；无 `spaces` 视为只有虚拟「全部」。`snapshot()/adopt()/load()` 透传并清洗：删除悬空 groupId、去重、限制数量（≤12）、名称长度（≤12 字）、theme/density 枚举。**当前空间是本机状态**，与 `settings.net` 同级保存在本机，不进服务器版本号、不触发冲突。服务端 `validate` 加 spaces 结构校验（类型、ID 格式、引用存在），畸形结构 422；保留 V1.1 URL 白名单、aliases 限制、403/409/422 用例全部通过。补测试：旧配置升级、同组多空间、删分组清引用、删空间不删项目、换账户不泄露空间与本机选择、导入/导出/备份恢复、用 `sha-3e6da3c` 旧版读写新数据后空间定义是否保留（实测记录，不靠「未知字段透传」宣称）。
2. **空间管理与跨端交互**：把本预览的管理面板、空状态、桌面左栏 / 手机拇指区切换器接到真实数据；分组顺序保持**全局统一**；命令面板跨空间搜索与 `>` 操作并入现有 `cmdrank.js`，不另造 `A.url`。
3. **视觉系统落地**：抽出 tokens、三层背景、材质、卡片与动效到独立 CSS；每台设备「经典 / 新版」外观开关（本机保存），两种外观共用同一份 DOM 与业务逻辑；初期默认经典。保留用户壁纸、暗度/模糊、时钟/搜索开关。
4. **回归与发布准备**：浏览器自动化截图与录屏、375–1920 溢出检查、减少动态效果、iPhone 主屏模式（无真机即标「未验证」）；README 与 `docs/v2.0-report.md`；CI `test → build` 通过后给固定 `sha-<commit>` 镜像；回滚路径为 `ghcr.io/sadjdg123/nocturne:sha-3e6da3c`，无需清空 `/data`。不自动部署 NAS。
