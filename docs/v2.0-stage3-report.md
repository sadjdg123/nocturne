## 2. 删除语义（自定义空间）

**规则**：项目在空间 S 里可见 ⇔（所在分组整组在 S 里 **且** 不在 `S.excludeItemIds`）**或** 在 `S.itemIds` 里。`itemIds` 与 `excludeItemIds` 互斥（单独加入会取消隐藏，隐藏会取消单独加入）。排除只对整组包含的分组有意义：项目被删、或分组不再整组在 S 里时，`prune()` 清掉这条排除；列表为空时删掉字段。

| 场景 | 编辑模式的减号 |
| --- | --- |
| 「全部」 | 和以前一样直接删除 + toast「撤销」 |
| 自定义空间 | 动作面板，标题「「项目名」」+「要从哪里去掉它？」。第一项（默认、获得焦点）「从「空间名」移除」：单独加入的 → 取消加入；随整组出现的 → 说明「分组「X」整组在这个空间里：只在本空间隐藏这一项…」并写一条排除。第二项红色「从所有空间删除…」→ 第二个面板「删除「项目名」？它出现在 N 个空间里（全部、娱乐…）。删除后所有空间都不再有它…」+ 红色「删除项目（N 个空间）」/ 取消；Esc / 点遮罩 = 取消 |

点按项目弹出的菜单同样改为「从「X」移除」（只要项目在本空间可见）和「从所有空间删除…」（再确认）。所有修改走 `App.commit`，可撤销、会同步。分组标题显示「本空间隐藏 N 项」；管理空间的「单独添加 / 隐藏项目」里，整组分组的项目可以取消勾选（= 隐藏）、再勾上（= 取消隐藏）。

**数据**：`spaces.js` SCHEMA 1 → 2，`KNOWN_BY_VERSION[2]` 加 `excludeItemIds`；`check()` 像 `itemIds` 一样校验（字符串数组、≤500、id 合法），服务端畸形值 400 `bad_spaces`；前端 caps 变为 `["spaces","spaces:2"]`。阶段 2 的 schema 1 客户端不认识这个字段，漏掉时服务器按 caps 补回（`spacesRestored`）——已测。阶段 2 forward-compat 测试里的「更新的客户端」相应从 schema 2 改成 schema 3。

## 3. 可信状态

| 来源 | 显示 |
| --- | --- |
| 服务器真的探测了（NAS 模式 `/api/status`） | 在线 · 23 ms · 检测于 21:46 / 在线 · 需登录 / 离线 · 检测于 …；延迟只在服务器测到时显示，关联容器判定的在线不编延迟 |
| 服务器没给这一项（新项目、普通账户、.local） | 浏览器探测：成功 =「可能在线」（空心冷青点），失败 =「无法确认」；从不显示延迟和时间 |
| 纯静态模式 | 同上；状态卡「x / y 可能在线」「浏览器无法确认真实状态：…」 |
| 没有地址 / 示例域名 / 服务器策略不探测 | 未检测（不计入总数） |

状态卡、读屏播报、命令面板「刷新状态 / 重新检测状态」报告都改用这套口径（静态：「检测完成：2 个可能在线，1 个无法确认（浏览器检测无法确认真实状态）」）。去掉了旧代码里「浏览器探测用 `performance.now()` 算出的伪延迟」。`public/` 里没有任何「模拟数据」字样（测试断言）。

## 4. 设计系统

**Tokens**（`midnight.css` 第 1 节，`html[data-ui="v2"]` 作用域）：Ink `#0A0D14`、Night `#121A2B`、Dome `#1C2A44`、Amber `#E7B467`（只给交互：当前空间指示、选中引擎点、主按钮、选中行）、Frost `#8FC9D6`（只给信息：在线、延迟）、Paper `#ECE6DA`、Mist `#98A1B3`、Coral `#E59079`（离线）；三档描边、材质渐变、内高光、两档阴影；圆角 8/11/14/18/22；缓动 `cubic-bezier(.2,.75,.2,1)` / `(.65,0,.35,1)`；时长 80/160/240/420/660ms。旧的 `--x-*` 变量映射到新 tokens，所有旧浮层自动换色。

**三层背景**：① 用户壁纸（`.x-bg` / `.x-wp` + 暗度 / 模糊设置，全部空间共用，原样保留）→ ② 光层 `.mn-sky`：每个氛围一层穹顶光（径向 + 锥形光束渐变）、一道切换时扫过的光、暗角、静态 SVG 颗粒 → ③ 内容材质（半透明午夜蓝渐变 + 1px 纸色细边 + 顶部内高光）。

**排版**：只用仓库自托管字体。时钟 Cormorant Garamond 300（`lnum` + `tnum`），品牌 / 空间名 / 分组标题 / 问候 Noto Serif SC 500，正文系统无衬线，数字全部 `tabular-nums`。

**毛玻璃预算**：桌面同屏 0 处（命令面板打开时 1 处）；手机：搜索栏 + 底栏（命令面板打开时 3 处）。桌面搜索栏改用较不透明的同种材质：它下面是会换色的光层，模糊每帧重算，实测切换空间时 >34ms 的帧从约 15 帧降到约 4 帧。

**焦点**：纸色 1.5px 描边；搜索框聚焦只是边框变亮 + 极淡外晕，没有琥珀色。

## 5. 每个空间的样子

外观来自空间字段 `theme` / `density`（已有字段）。没设时按名称模板给默认（只影响样子，不碰分组归属）：日常 → 晨光 + 舒适，娱乐 / 影音 → 靛紫 + 海报，NAS / 存储 / 服务器 → 冷霜 + 紧凑，其余（含「全部」）→ 中性 + 舒适。管理空间里每个空间可以选「氛围：自动 / 中性 / 晨光 / 靛紫 / 冷霜」「密度：自动 / 舒适 / 海报 / 紧凑」（走 commit，同步）。

| 密度 | 桌面 | 手机 |
| --- | --- | --- |
| 舒适 | 横向卡：40px 真实图标 + 名称（两行截断）+ 描述，`minmax(200px,1fr)` | 默认 3 列（图标 46px + 名称两行）；可选紧凑 4 列 |
| 海报（娱乐） | 172px 起的卡：按名称色相的色调封面 + 64px 真实图标 + 衬线标题 | 两列 |
| 紧凑（NAS） | 仪表面板里的行：28px 图标 + 名称 + 地址（按网络三态）+ 右侧真实状态（「12 ms」/「离线」/「需登录」/「可能在线」…） | 单列 |

图标：用户的自定义图标（上传到 `/api/icons`）和 Iconify（服务器缓存 `/api/icon/…`）优先；文字 / Emoji 图标照常；只有完全没有图标或加载失败时才出现克制的字母徽记（图标尺寸内、按名称色相的暗色渐变），从不放大成主视觉。长名称两行截断，完整名称在 `title` 和动作面板标题里。

布局：≥1200 且有自定义空间 = 左栏空间索引（滑动指示条）｜中栏（时钟 + 当前空间标题、搜索、分组）｜右栏（系统状态、最近使用，sticky）；900–1199 = 两栏，切换器在搜索下方横排；768–899 = 单栏横向卡；<768 = 手机独立排版。

## 6. 动效

| 时刻 | 做法 | 时长 |
| --- | --- | --- |
| 页面载入 | 纯 CSS 分层：壁纸 → 光层 → 头部 → 时钟 → 搜索 → 空间 → 分组 → 右栏 / 底栏，淡入 + 上移 12px | 560–900ms，延迟 60–300ms |

## 7. 手机

- **一条悬浮底栏**（不是两层）：`快速打开`（图标，琥珀）｜可横滑的空间分段（指示条，边缘渐隐）｜`更多`（编辑 / 添加 / 管理空间 / 设置）。没有自定义空间时 =「快速打开 / 编辑 / 设置」。DOM 上是把原来的 `.x-spaces` 挪进 `.x-dock`（只在新版 + <768px，宽度变化时挪回），切换器逻辑不变。
- 正文底部留白 = 栏高 + 30px + `env(safe-area-inset-bottom)`，实测最后一张卡底 714px < 栏顶 774px；左右安全区计入栏宽。
- 软键盘：`visualViewport` 变小（>120px）且焦点在输入框 → `html.mn-kb`，底栏 / 编辑栏下移淡出；命令面板原有的 `fit()` 把面板放进可见区域。
- 抽屉开着时提示条移到顶部，不盖住选项。
- 编辑模式下底栏换成编辑栏（撤销 / ＋分组 / 完成），这时切换空间要先点「完成」，或用命令面板 `>` 操作（已知限制）。

## 8. 设置与迁移

- **新版 / 经典**：设置 → 外观 → 界面。只存本机 `localStorage["nocturne.ui"]`；**v2 分支默认新版**，经典随时可切回。两者共用同一份 DOM、数据和全部功能；切换不 commit、不同步、不动壁纸和任何设置（测试断言 state 字节不变、零 PUT）。首帧前由 `<head>` 里的小脚本设好 `html[data-ui]`，不会先闪经典。
- **手机列数**：新版用本机 `localStorage["nocturne.v2.cols"]`（3 标准 / 4 紧凑），**不同步**——这是每台手机的手感选择，也不去改经典外观同步的「手机每行」。从没设过时迁移：经典「手机每行」为 5 → 4，其余（含默认 4）→ 3。新版里隐藏经典的 3/4/5 行，切回经典照旧。
- 显示开关（时钟 / 秒 / 日期 / 问候 / 搜索 / 状态 / 最近）、壁纸、暗度、模糊、标题全部原样生效；问候与日期合成一行时，关掉问候则日期单独显示。

## 11. 未验证 / 风险

- **未验证**：iPhone Safari 真机（软键盘、安全区、主屏幕模式、毛玻璃与渐变的功耗与流畅度、`:has()` 依赖 iOS 15.4+）、Mac Safari、Android Chrome 真机、真实 HTTPS 反代、群晖 NAS 实机、屏幕阅读器实际朗读。软键盘是通过改写 `visualViewport` 模拟的，不等于真机键盘。
- 截图里的服务地址是本机模拟服务（127.0.1.x），图标来自本地 Iconify 上游；字体渲染在 Linux 上与 Apple 设备有差异。
- 无 GPU 的 headless 下切换空间第一帧约 200 ms；真机有 GPU 合成应明显更好，但未实测。
- 衬线字体扩展子集 492 KB 会在出现生僻字时下载（`font-display: swap`，不阻塞），弱网首屏体积比经典大。
- 手机横屏（844×390）首屏仍主要是时钟、搜索和切换器，分组要往下滚。
