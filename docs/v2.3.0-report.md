# V2.3.0 · 手机首屏、常用、一句话状态、图标墙、网址直达、编辑防误触、导入浏览器书签

基于 main `f831ad6`（V2.2.2 + 发布登记）。来源：设计团队（产品 / 视觉 / 手机交互三位设计师）在 iPhone 13 / SE 视口对演示站的走查，用户从候选中选定本版内容。

不改数据格式、接口、认证事务、Cookie 默认名、空间语义与同步逻辑；新增的本机数据只有 `localStorage["nocturne.freq"]`（常用排序，不同步）。CSP 不变（没有新增内联脚本）。

## 更新

### 新版（Midnight）手机

- **首屏压缩**：时钟与问候 / 日期并排，引擎（Google / 豆瓣）并进搜索行；首个分组从 y≈378 上移，首屏多出一行内容。关掉时钟时问候独占一行；称呼过长截断。
- **常用**：搜索栏下面一行（横滑，最多 8 个），按本机点按次数为主、最近使用为辅排序；只在载入 / 回到前台时重排，点完不会立刻换位置；新用过的项目在没满 8 个时接在末尾。跟随「显示 → 最近使用」开关；编辑模式下隐藏；有它时页底的「最近使用」卡在手机上不再显示。
- **当前空间名**：手机看不到右侧空间标题，问候下面的日期后带上空间名（「11月6日 星期五 · 娱乐」；「全部」时不带）。
- **图标墙**：设置 → 外观 → 手机每行「4 图标墙」（原「4 紧凑」）改成 iPhone 主屏幕式：没有卡片底，56px 统一图标底板，分组是一块淡面板；自选背景色轻度降饱和。编辑模式下虚线框与删除角标跟着图标走，「+」是图标大小的虚线方块。「3 标准」保持卡片样式；海报 / 紧凑行密度不受影响。

### 新版（Midnight）全尺寸

- **一句话状态**：卡片上只标出问题——在线 / 需登录 / 检测中不再挂点，离线是珊瑚点，无法确认是空心圈；全部都连不上时连珊瑚点也不画、名字不压暗。网络胶囊带上「N 个连不上」（服务器确认的离线数，当前空间范围）：桌面「自动·内网 · 3 个连不上」，手机只显示「3 个连不上」，网络模式在点开的菜单里；读屏的 aria-label 同时包含两者。
- 桌面右栏离线名单最多约 4 行，其余在框内滚动。
- **「显示 → 系统状态」开关管全部状态显示**：关掉后状态卡、图标上的小点、紧凑行的状态文字、胶囊里的「N 个连不上」都不显示，离线项名字不压暗（两种外观）。后台检测照常，命令面板仍可刷新。背景：状态由 NAS 检测，Plex 等对未登录请求返回 401 时显示「需要登录」，与用户在浏览器里是否登录无关，容易误解，用户选择整体关闭。

### 两种外观

- **网址直达**：顶部搜索框输入 `douban.com`、`www.douban.com/subject/1`、`nas.local:5000`、`192.168.1.10:8096`、`https://…` 回车直接打开；没写协议时 IP / localhost / .local / .lan / .home.arpa / 带端口用 http，其余 https。只认常见顶级域名，`node.js`、`index.html`、`v2.3`、`三体` 等照常搜索；`javascript:`、`mailto:` 等其他协议不当网址。命令面板输入网址时第一行是「打开 …」，回车即开。
- **编辑防误触**：编辑模式图标改为 `touch-action: pan-y`，触屏按住约 0.28 秒才拖起（`delay: 280, delayOnTouchOnly, touchStartThreshold: 8`，鼠标不受影响）；被选中那一刻起 touchmove 一律 preventDefault。上下滑动是滚动页面，不会一碰就把图标拖走。
- **撤销更稳**：带按钮的提示（撤销等）停 8 秒，手指按住提示时暂停计时、松开后再给 3 秒；按钮 40px 高。命令面板新增「撤销上一步」（输入「撤销」「误删」等可找到）。
- **导入浏览器书签**：设置 → 数据 → 导入浏览器书签，选浏览器「导出书签」得到的 .html（Chrome / Edge / Safari / Firefox 通用的 Netscape 格式）。按最内层文件夹分组预览、勾选；跳过首页已有的地址（内网 / 外网任一相同，忽略 www、末尾 /、http/https 差别）和文件内重复；只收 http(s)（小书签、file: 等不收）；一次最多 300 个。追加到同名图标分组或新建分组（在某个空间里导入时，新分组整组进这个空间）；私有地址进内网地址、其余进外网地址；图标按域名去图标库找同名图标，找不到显示首字母。整个导入是一次提交（一步撤销、一次同步）。解析在新文件 `public/bookmarks.js`（纯函数，Node 可测）。

### 经典外观缺陷修复

- 手机底栏：`.x-dock button { display: grid }` 盖过了「快速打开 / 更多」的 `display: none`，3 列网格里放了 5 个按钮，「设置」「更多」掉到底栏下面。现在只有 搜索 / 编辑 / 设置 三格。
- 时钟开启 `lnum`：Cormorant 的旧式数字「1」不再像大写「I」。

## 缓存与兼容

- `midnight.css?v=4 → 5`、`midnight.js?v=3 → 4`（手写版本号，内容变了必须换）；`app.css`、`app-ui.css`、`app.js`、`app-ui.js` 的 `?v=` 按内容 sha256 重算；新文件 `bookmarks.js?v=1`。
- 已发布版本的 URL 与内容约束（`test/fixtures/released-assets.json`）不变，旧版本浏览器缓存不会串版本。
- 导入的项目、分组都是现有字段（`id / title / desc / lan / wan / icon`，分组 `style: "icon"`），旧版本读写无变化。
