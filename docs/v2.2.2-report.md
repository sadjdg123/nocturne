# V2.2.2 · 手机不再下载桌面壁纸

基于 main `6e81cf3`（V2.2.1）。只改 `public/index.html` 一个属性；数据格式、接口、认证、同步、带 `?v=` 的静态资源 URL / 内容全部不变。

## 问题

首页有两张默认壁纸：`bg-mobile.jpg`（约 60 KB，窄屏显示）和 `bg-desktop.jpg`（约 280 KB，≥768px 显示）。两者都是 `<img src>`，靠 CSS `display: none` 切换；浏览器对 `display: none` 的普通图片照样下载，所以手机首次打开会白下 280 KB 用不到的桌面壁纸。

手机尺寸审计（iPhone 13 视口、4 倍 CPU 降速、约 10 Mbps / 80 ms 网络，60 个项目）：首次打开共传输约 763 KB，其中桌面壁纸占 280 KB（约 37%）。

## 更新

- `bg-desktop.jpg` 的 `<img>` 加 `loading="lazy"`。按 HTML 规范，延迟加载的图片只在进入视口时请求；`display: none` 没有布局盒，永远不会进入视口，所以窄屏不再请求。宽屏下它本来就在视口内，布局后立即加载。
- `bg-mobile.jpg` 保持立即加载（手机首屏背景不受影响）；≥900px 的 `html` 兜底背景仍引用同一个 `bg-desktop.jpg`，只在宽屏规则生效时请求。
- 自定义壁纸、模糊 / 暗度、`visibility: hidden` 切换逻辑都不变（JS 仍按 `.x-bg` 取两张图）。
