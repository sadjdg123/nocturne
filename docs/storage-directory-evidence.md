# 第一阶段补查：合法账户目录的 .tmp 后缀

用户名规则一直允许 `bob.tmp`。备份工具旧规则将所有 `.tmp` 名称剪枝，导致该账户图标/环形备份目录遗漏；P1-1 的孤立数据枚举也略过这类目录，在认证文件均缺失且仅剩该账户资产时会错误开放初始化。

本阶段补查分别固化两个备份反例和两个启动反例：保留合法资产及空目录、拒绝控制字符目录，以及仅剩 icons/backup 下 `.tmp` 账户目录时启动退出 2 并保留原字节。旧工具及修复前服务器分别 2/2 失败，修复后通过。

临时文件排除仍保留，但仅对普通文件应用；目录和链接不能因后缀而被当作空站点证据略过。备份不支持链接，会明确拒绝；关键数据保护对异常目录继续保守阻断。没有更改用户名、数据格式、配置、Cookie 或 UI。
