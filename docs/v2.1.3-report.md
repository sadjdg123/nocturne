## 更新

- 同步：后台拉取、启动恢复、迁移规范化读取和冲突选择绑定捕获内容与版本，迟到响应不能覆盖后续编辑。
- 配置：前后端共用轻量结构/身份校验；损坏本机缓存保留原始恢复材料，防止默认配置被误推到 NAS。保留正常历史配置和扩展字段。
- 备份：导出完整读取当前图标；导入、重置等待备份并复核操作仍有效；资源失败时保留原内容。升级快照保留合法 `.tmp` 账户目录及普通文件。
- 媒体：内嵌图标迁移遵守整批配额；清理仅作用于本操作未提交资源；壁纸按实际内容重新校验缓存。
- 编辑：保留用户最后填写的高级 LAN/WAN 地址。
- 探测：立即连接错误不再导致未处理异常退出，保留地址固定和既有 SSRF 规则。
- 配额补修：目录/文件统计只忽略明确 ENOENT；EIO、EACCES 等错误阻止本次分配，不再漏计后继续写入。无图标分配的普通配置保存仍不依赖图标目录健康。

数据格式、空间语义、默认 Cookie 名、认证事务、公网 Secure Cookie 策略、UI 和生产发布工作流不变。继续保留 `NOCTURNE_SECURE_COOKIE_HOSTS=jingbo.men`，内网 HTTP 使用方式不变。

## 升级与回滚

由用户手动停写备份并固定新镜像升级，本轮不操作 NAS 或 Cloudflare。JSON 导出仍不包含壁纸文件；老浏览器的旧 immutable 壁纸缓存需刷新后接收新策略。回滚可使用上一版固定 SHA 镜像，历史镜像和记录保留。
