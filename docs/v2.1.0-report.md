# Nocturne V2.1.0 · Midnight Edition

将用户确认的四场景视觉提案接入现有 Midnight 外观。右侧模块全部关闭时收回整列，小分组按原顺序并排、大分组完整展示；收紧时钟、问候与搜索的首屏比例，提高卡片和文字对比。手机沿用原有列数、底栏和触控操作，经典外观保留。

## 变更范围

- `public/midnight.css`：桌面自适应右栏、两列小分组、整行大分组与视觉层次；空分组浏览时隐藏，编辑时仍可访问。
- `public/midnight.js`：只标注当前可见分组大小与可用宽度，不改配置、项目顺序或空间引用。没有新增布局引擎。
- `public/index.html`：Midnight CSS/JS 缓存 URL 更新为 v4/v3。
- `package.json`：版本 2.1.0，语法检查补上 Midnight 行为文件。
- `test/midnight-layout.test.js`：2 项回归，检查旧配置、编辑撤销、经典切换、空间排除项目和分组可见数量。

数据格式、认证、Cookie 名称、搜索逻辑、管理操作及备份恢复代码均未改动。没有数据迁移；可切回经典外观，或沿用原来的 V2.0.0 固定镜像回滚。NAS 升级前仍应停写备份，由用户执行。

## 验证

本地 Node 22 语法检查通过；相关自动化测试 25/25，零失败、零跳过。真实 Chrome 使用产品前端副本和隔离模拟数据检查 A–D 四场景、原版设置开关、手机三列和快速打开搜索；无横向溢出。1440×900 主区 A 约836px、B约1112px；大分组与主区等宽。手机390×844检查不代表iPhone Safari真机验收。

完整自动化测试、双架构构建和固定镜像将在现有 Docker Actions 完成后登记。本次不修改发布工作流，不创建版本标签，不改 main，不操作 NAS/Cloudflare/生产数据。
