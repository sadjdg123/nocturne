# V2.4.0 · 网站图标抓取、剪贴板粘贴、桌面效率包、单项目静音状态与分组折叠

基于 main `ab8229b`（V2.3.0 + 发布登记）。聚焦「不增加页面视觉负担、日常高频顺手」的实用升级，保持零运行依赖、严格 CSP、现有数据与回滚兼容约束不变。

不改认证事务、Cookie 默认名、快照环、壁纸存储结构与空间语义；新增可选字段仅 `item.noProbe`（单项目不检测状态）与 `engine.kw`（自定义搜索引擎触发词），旧版本读写原样保留；本机新增 `localStorage["nocturne.collapsed"]`（分组折叠状态，不同步）。

## 更新

### 1. 图标更省心

- **一键抓取网站图标（`POST /api/icons/fetch`）**：编辑项目弹窗的「自动」与「图片」面板新增「抓取网站图标」。服务端严格复用 `vetTarget` 防 SSRF（拦截元数据 / 链路本地 / 本机 Nocturne 端口、固定解析 IP、重定向最多 3 跳逐跳复检，普通账户沿用 `PROBE_ALLOW` 白名单），自动识别页面 `<link rel="apple-touch-icon">` / `icon` 与 `/favicon.ico` 回退，支持将 `.ico`（内嵌 PNG 或标准 DIB 位图）零依赖转为安全 PNG，并走现有账户图标配额与 24h 孤儿清理（拒绝 SVG）。
- **粘贴剪贴板图片**：在添加 / 编辑项目弹窗打开时直接按 `Ctrl+V` / `⌘V` 粘贴图片，自动裁剪缩放为 128×128 并上传为项目图标；粘贴普通文本照常进入输入框。

### 2. 桌面效率包

- **卡片毛玻璃右键菜单**：桌面非编辑态右键点击卡片或快捷链接，弹出轻量操作菜单（有双地址时提供「用内网地址打开 / 用外网地址打开」，单地址提供「在新标签页打开」、复制网址、直接编辑项目）；按住 `Shift` 右键保留浏览器原生菜单；触屏设备长按仍进入编辑模式。
- **搜索框快切引擎与触发词**：聚焦主页搜索框按 `Tab` / `Shift+Tab` 循环切换已启用搜索引擎；输入短触发词加空格直接用指定引擎搜索（内置默认 `g` Google、`bi` Bing、`b` 百度、`gh` GitHub，可在 设置 → 搜索 添加引擎时自定义 1–8 位字母数字触发词）。
- **`⌘K` 中文拼音首字母搜索**：新增零依赖 [public/pinyin.js](../public/pinyin.js)（基于标准 `Intl.Collator("zh-CN")` 声母分界与常见多音字补丁），接入 `cmdrank.js`，在命令面板输入 `bqh` 可直接命中并高亮「白群晖」，输入 `yy`、`sz`、`cx` 亦可命中中文分组与内置操作。

### 3. 系统状态更实用

- **单项目「不检测状态」**：项目编辑「更多」里新增「不检测状态」开关（`item.noProbe: true`）。开启后服务端与浏览器均不再探测该项目，不画状态点，也不计入离线统计或未检测提示。
- **头部胶囊离线清单与即时重测**：点击头部「自动 / N 个连不上」胶囊菜单时，若有连不上的服务会直接列出可点击的离线名单（手机端也可直达），并提供「立即检测状态」按钮（桌面状态卡标题右侧同步增加 `↻` 按钮，命令面板新增「立即检测状态」动作）。后端新增 `POST /api/status/recheck`（带 10 秒防抖冷却；普通账户仅重测自身符合 `PROBE_ALLOW` 的地址），保留原有「刷新状态」缓存读取语义不变。

### 4. 分组折叠

- 非编辑模式下点击分组标题（或聚焦按回车 / 空格）可折叠或展开该分组；状态记在本机 `localStorage["nocturne.collapsed"]`，不同步也不触发版本更新。进入编辑模式自动展开，退出后恢复；通过 `⌘K` 跳转到已折叠分组时自动展开。
