# 夜曲 Nocturne · V2.0 RC.5（2.0.0-rc.5）

RC.5 整合已验收的可靠性修复与 Linux 工程兼容修复，没有新增产品功能或界面变化。

## 更新

- 持久化文件损坏、缺失或读写异常时停止相关操作，保留原账户和配置，避免被当作首次初始化。
- 账户、密码、会话、设备登记通过最小跨文件事务持久提交，成功后才更新内存及发放 Cookie；标记前后中断、状态核验失败及退休目录部分清理均可按严格规则恢复。
- 热备份检查完整文件清单，恢复工具保留失败回退及异常中断材料；完善停写完整备份流程，修复 BusyBox inode 前导空白与备份输出路径兼容问题。
- RC.4 已纳入静态资源缓存基线；GHCR 只读检查支持受限的 blob CDN 跳转。
- 原生 amd64/arm64 Linux 构建、实际启动、SIGKILL、停写备份恢复与完整测试已通过。

## 人工升级与回滚

由用户自行升级 NAS，先停写并按 `stopped-backup.md` 保存和校验完整备份，再使用本次固定镜像 digest。账户、配置、空间和默认 Cookie 与 RC.1–RC.4 的正常数据兼容。

旧 RC 不理解新增认证事务恢复记录；回滚前先让 RC.5 完成恢复并正常停止，不能把旧镜像直接接管半完成事务。无法恢复时保留现场，使用已校验的停写备份；详见 `engineering-rollback.md`。

Linux 验证不代替 DSM 磁盘性能或真实断电验收。认证同步提交增加磁盘 I/O，测量与适用边界见 `phase2-engineering-report.md`。本次没有操作 NAS 或生产数据。
